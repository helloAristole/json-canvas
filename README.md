# JSON Canvas

JSON Canvas 是一个纯前端的 JSON 可视化编辑器：左边编辑带高亮和校验的源码，右边把对象、数组展开成卡片关系图，两边实时同步、点击即可互相定位。关系图只读结构、不改字段类型，需要时可以就地改 Value；数据只存在浏览器本地，适合把复杂 JSON 摊开看结构、对照字段，再写回源码。

开发服务默认地址：`http://127.0.0.1:5173/json/`。

## 功能

- **源码编辑**：JSON 语法高亮、实时校验、格式化、复制；可调字号（`Ctrl` + 滚轮 / `Ctrl` `+` `-` `0`）
- **关系图**：对象与数组展开为卡片，正交连线、紧凑树形布局；节点不可拖动，字段类型与 JSON 保持一致
- **双向定位**：图中字段与源码范围互相高亮；右键可定位父节点，或通过「前往」跳到子节点
- **就地改值**：双击或右键编辑 Value（不改变类型）；源码侧可复制 Key / Value
- **搜索与折叠**：按键、值或路径搜索；单节点、单分支或全部展开 / 折叠
- **多文档**：顶部标签切换多个 JSON；导入、拖入 `.json` 文件，或下载当前内容
- **本地状态**：工作区自动写入 `localStorage`；深浅色主题、编辑器字号会记住；编辑后关闭或刷新页面会提示确认离开

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

构建产物按 `/json/` 路径部署。
