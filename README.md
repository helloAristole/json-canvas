# JSON Canvas

一个纯浏览器端的 JSON 可视化编辑工具。把「文本编辑」和「结构视图」放进同一屏，左边改源码、右边实时看结构，两侧双向联动。**所有解析与渲染都在浏览器本地完成，数据不会上传到任何服务器。**

在线体验：<https://helloaristole.github.io/json-canvas/>

## 核心特性

### 双栏联动：源码 ↔ 结构图
- 左侧为 CodeMirror 驱动的源码编辑器，右侧为自动布局的 JSON 结构图，同一份数据两种视角。
- **双向定位**：点击图上节点，源码中对应行高亮跳转；在源码中移动光标，图上自动选中对应节点。
- 分栏宽度可拖拽调节，源码面板可整体收起，专注看图。

### 可视化浏览与操作
- 节点卡片支持**展开 / 折叠**，以及按分支整棵子树收起，大 JSON 也能看清主干。
- 卡片上**双击即可编辑值**，数字、布尔、对象、数组和 `null` 可以互相改，保存后写回源码。字符串里直接输入 `null` 会存成 JSON `null`。
- 右键菜单可**复制键名、复制值、复制 JSONPath 路径**（如 `$.user.tags[0]`），也可复制整个节点。
- 支持选中节点与连线，深层嵌套结构一目了然。

### 搜索与定位
- **源码搜索**：支持查找、替换、替换全部，匹配项高亮并可逐个跳转。
- **图上搜索**：按字段名 / 路径搜索节点，支持 `$.a.b[0]` 这类 JSONPath 语法，一键定位到深层字段。

### 多文档工作区
- 顶部**多标签页**管理多个 JSON 文档，可自由新建、切换、重命名、关闭（中键快速关闭）。
- 工作区与文档内容**自动保存到浏览器本地**，刷新页面不丢失。

### 导入与导出
- 打开本地 `.json` 文件、从**剪贴板直接粘贴** JSON 内容。
- 下载为 JSON 文件；也可把**整个画布导出为 PNG 图片**，方便贴到文档或分享。

### 历史记录与版本对比
- 编辑过程**自动记录历史快照**，可随时回溯、恢复、删除。悬停一条记录可以预览带语法高亮的 JSON。
- **版本对比**：当前文档和其他已打开的标签页做 diff，差异标注后可跳到对应字段。

### 编辑辅助与校验
- 一键**格式化**为带缩进的 JSON。
- **实时语法校验**，顶部即时显示「有效 JSON」或「语法错误」及错误原因。
- 编辑器支持语法高亮、括号匹配、代码折叠、括号自动闭合、当前行高亮。
- 编辑器字号可调（按钮或 `Ctrl + 滚轮`）。

### 统计与外观
- 实时统计：文件体积、节点总数、对象数、数组数、**最大嵌套深度**。
- 支持**深色 / 浅色主题**切换，采用 Geist Mono 等宽字体，观感统一。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl / Cmd + F` | 查找（焦点在源码面板时搜源码，否则搜结构图） |
| `Ctrl / Cmd + H` | 替换 |
| `Ctrl / Cmd + Enter` | 替换全部 / 确认编辑 |
| `Ctrl / Cmd + Shift + V` | 从剪贴板打开 JSON |
| `Ctrl / Cmd + Shift + Backspace` | 清空当前 JSON |
| `Ctrl + 滚轮` | 调节编辑器字号 |
| 双击节点卡片 | 编辑该字段的值 |

## 技术栈

- **框架**：React 19 + TypeScript + Vite
- **源码编辑器**：CodeMirror 6（`@uiw/react-codemirror` + `@codemirror/lang-json`）
- **结构图**：React Flow（`@xyflow/react`）+ `elkjs` 自动布局
- **图片导出**：`html-to-image`
- **图标 / 字体**：`lucide-react`、`@fontsource/geist-mono`

## 本地开发

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器
npm run build   # 类型检查 + 生产构建（输出到 dist/）
npm run preview # 本地预览构建产物
```

默认构建路径是 `/json/`。部署到其他子路径时设置 `VITE_BASE`，例如 GitHub Pages 使用 `/json-canvas/`。部署到站点根路径时设为 `/`。

## 部署

推送到 GitHub 仓库的 `main` 分支后，Actions 会自动构建并发布到 GitHub Pages。
